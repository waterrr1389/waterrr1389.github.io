很多人以为暗色模式就是"黑底白字"，但对我这种有散光的眼睛来说，纯黑（#000000）配纯白（#ffffff）的组合是最刺眼的：文字边缘会出现光晕，看久了眼睛酸胀。

## 问题出在对比度

散光会把高对比的边缘"散开"。纯白文字在纯黑背景上，每个字都像灯泡一样往外溢光。解决办法其实很简单：**两边都退一步**。

- 背景不用纯黑，用深灰，比如 `#1c1c1e`
- 文字不用纯白，用米白，比如 `#e3e3e0`
- 强调色从亮蓝换成更柔和的 `#0a84ff`

这样对比度从 21:1 降到大约 13:1，依然在 WCAG AAA 的可读范围内，但光晕明显减少了。

## 图片也要处理

暗色主题下，亮图片比文字更刺眼。一行 CSS 就能缓解：

```css
[data-theme='dark'] img {
  filter: brightness(0.9);
}
```

## 切换时别闪白

最后是个工程细节：主题判断要在页面渲染前完成，否则暗色用户每次打开页面都会先看到一帧白屏。把判断脚本内联在 `<head>` 里、设置好 `<html data-theme>` 之后再渲染 body，闪烁就消失了。

这个博客的暗色模式就是按这套思路做的。如果你在暗色下阅读这篇文章，希望你的眼睛是舒服的。
